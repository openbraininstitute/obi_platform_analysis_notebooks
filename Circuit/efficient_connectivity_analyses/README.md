## Summary
The purpose of this notebook is to teach efficient coding schemes for the analysis of large-scale neuronal connectivity data. That is, connectivity at neuronal resolution in entire circuits or even brain regions.

## Use
After authentication with the OBI platform and selection of a circuit model on the platform, the connectivity of the model is downloaded.

Then, the user follows along as a number of different ways to implement connectivity analyses are contrasted.
