## Summary
In this notebook the user selects a cell surface mesh, which is then turned into a morphology skeleton in all common formats (.swc, .asc, .h5) and all spines are extracted. Representation of the morphology-with-spines is backwards compatible with the neurom and morphio python packages (but will appear as a "smooth" morphology without spines). To access the spines, a utility package is provided by OBI and listed on the pipy package index.

## Use
Simply run the cells of the notebook, following the listed instructions.
